# DeepCore Roadmap

## Foundation

- Preserve the event-sourced deterministic core
- Establish cryptographic identity and private PKI
- Define invariants and replay semantics

## Distributed execution

- HotStuff-style consensus and quorum certificates
- BLS signature implementation
- Kafka/NATS transport
- Kubernetes/Istio/SPIFFE deployment
- Adversarial and chaos testing

## Financial integration

- Bitcoin Core integration
- Lightning and Liquid interfaces
- NBL v2 commitments
- DC02 anchoring
- Treasury reconciliation and accelerator controls

## Verification

- TLA+ distributed-state specifications
- Lean proof development
- Runtime invariant enforcement

## AI and augmentation

- OpenAI Responses/Agents integration
- Launch Desk agent
- Controlled QSI quantum augmentation

All production milestones require testing, security review, reproducibility, and operational rollback plans.
