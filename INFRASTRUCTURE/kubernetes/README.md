# Kubernetes

Kubernetes is the target orchestration layer for containerized DeepCore services.

## Responsibilities

- Workload scheduling and lifecycle management.
- Service discovery and controlled networking.
- Resource limits and health checks.
- Secret references through an external or cluster secret-management mechanism.
- Declarative deployment of versioned services.

Production deployments require least privilege, network policy, workload identity, resource boundaries, backup/recovery procedures, and tested rollback paths.
